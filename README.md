# Chetana Kolhe — AI & Data Science Portfolio

A modern, high-performance portfolio website engineered with **React**, **Vite**, and **Tailwind CSS**, designed with modern dark aesthetics, glassmorphism cards, and responsive navigation.

## 🌟 Features Included

- **Modern Dark Aesthetic**: Radial glow meshes, glassmorphic cards, smooth hover micro-interactions, and neon accent badges.
- **Hero Section**: Includes a live interactive Python code widget (`chetana_profile.py`), direct contact quick-actions, status badges ("Open to Internships"), and profile metrics.
- **About Me Section**: Highlights career objective, academic focus at RCPIT Shirpur, interpersonal strengths, and verified competencies.
- **Skills Matrix**: Categorized interactive tabs for Programming (Python, C, Java), Data & AI / ML (Data Analytics, Predictive Modeling, IBM Tools), and Developer Tooling.
- **Experience Timeline**: Complete details of the **BharatCares (IBM SkillsBuild & AICTE)** Data Analytics with AI virtual internship and **Aaditya COEP** marketing internship.
- **Featured Projects**: Curated project cards with tech tags, summaries, and direct GitHub links.
- **Education & Certifications**: Detailed academic background (B.Tech at RCPIT, HSC, SSC with percentages) and certifications in DSA, AI Analytics, Java, and Git.
- **Interactive Resume Modal**: Full curriculum vitae preview matching the resume, complete with a print/save to PDF button.
- **Contact Hub & Form**: Direct one-click email copy, phone connection, social links, and an interactive message launcher.

## 🚀 Running Locally

1. Open a terminal in this directory:
   ```bash
   cd C:\Users\dell\.gemini\antigravity\scratch\portfolio
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your web browser.

3. Build for production:
   ```bash
   npm run build
   ```
   The optimized production bundle will be created in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, or Netlify.

## 🛠️ How to Update Your Information

All website text, links, projects, and contact information are centralized in a single file:
👉 `src/data/portfolioData.js`

To update any details (such as adding a new project or certification), simply edit `src/data/portfolioData.js` and the site will update automatically in real-time!
